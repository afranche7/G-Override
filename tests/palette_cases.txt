# How the Prompt Palette file is parsed. Both Helpers' tests parse every fixture listed here
# (and the same fixture with CRLF line endings) and compare the result with the items under it,
# so Windows and macOS read a palette file identically.
#
# [name.md] names a fixture in tests/palette/. The lines under it are the items it parses to, in order:
#   entry: <title>         a Palette Entry, followed by its fields:
#   body: <text>             the text to insert
#   send: true               auto-submit (omitted = false)
#   action: <name>           region-snip or window-snip (omitted = none)
#   separator:
#   group: <title>
# A fixture with nothing under it parses to no items.
# In values, \n is a newline, \t a tab and \\ a backslash.
# Blank lines and lines starting with # are ignored.

body: line one\nline two

body: line one\n\nline three
